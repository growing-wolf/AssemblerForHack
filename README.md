# Hack Assembler —— Nand2Tetris 项目6 汇编器（C++实现）

## 二遍扫描符号解析 · 二进制代码生成

================================================================================

## 项目简介

Hack Assembler 是一个将 Hack 汇编语言（.asm）翻译为 Hack 机器码（.hack）的汇编器。
本项目实现了《计算机系统要素》（Nand2Tetris）课程 Project 6 的全部功能，
支持 A指令、C指令和伪指令（L指令），采用二遍扫描算法处理符号标签。

采用 C++17 标准编写，使用 STL 容器管理符号表，零外部依赖。

================================================================================

## 功能特性

+ A指令翻译：@value 或 @symbol -> 0 + 15位二进制地址
+ C指令翻译：dest=comp;jump -> 111 + 7位comp + 3位dest + 3位jump
+ L指令处理：(LABEL) -> 记录符号到代码行号映射
+ 变量符号自动分配：从 16 开始递增
+ 预定义符号表：SP、LCL、ARG、THIS、THAT、R0-R15、SCREEN、KBD
+ 注释过滤：自动移除 // 后的内容
+ 空白字符清洗：移除空格和制表符

================================================================================

## 架构设计

第一遍扫描：符号构建
源文件 (.asm) -> 词法清洗 -> 识别 L指令 -> 符号表记录 (LABEL -> 行号)

第二遍扫描：代码生成
源文件 (.asm) -> 指令解析 -> A指令/C指令 -> 二进制编码 -> 目标文件 (.hack)

核心模块说明：

[Parser]      读取 .asm 文件，过滤注释和空白，解析指令类型和符号
[Code]        编码器，将助记符转换为二进制（dest/comp/jump 三张映射表）
[SymbolTable] 符号表，管理预定义符号和用户自定义标签

## 算法说明

### 第一遍扫描（符号构建）

1. 逐行读取清洗后的指令
2. 若遇到 L指令（例如 (LOOP)），将符号和当前行号存入符号表
3. 若非 L指令，行号计数器加1

### 第二遍扫描（代码生成）

1. 重新从第一条指令开始读取
2. 若为 A指令：
   - 判断符号是否为数字
   - 若为变量且不在符号表中，从 16 开始分配新地址
   - 若为预定义符号或标签，查表获取地址
   - 生成格式：0 + 15位二进制地址
3. 若为 C指令：
   - 解析 dest、comp、jump 三部分
   - 查表转换为二进制码
   - 生成格式：111 + comp + dest + jump
4. 跳过 L指令（已处理，无需生成代码）
